## 从下单到开通，实际流程是怎样的

流程本身不复杂，但有一步很多人会忽略。

1. **注册账号**。手机号或邮箱验证码登录，用 +86 号码就可以。
2. **选服务和时长**。选 Claude Pro，再选你要几个月的。
3. **本地网络环境检测**。这一步是重点，平台会在提交订单前检测你的 IP 类型、DNS 是否泄露、浏览器指纹和 IP 地区是否匹配。
4. **获取账号登录凭证**。按提示安装浏览器插件，插件会在你访问 Claude 时抓取登录凭证并回传，用于平台在官方页面上完成付款。
5. **支付**。微信或支付宝扫码完成，人民币结算。
6. **等待开通**。一般几分钟到半小时内在你的 Claude 账号里生效。

第 3 步值得单独说一句。这类代付对网络环境相当敏感：**住宅 IP（ISP 类型）通过率高，数据中心 IP、机房节点、公共机场的通过率很低**，因为后者在风控系统里天然是异常信号。如果你手上只有普通机场节点，成功率会明显打折。第 4 步则是另一个需要你自己判断的点，下面详细说。

## 买之前必须知道的几个限制

**登录凭证的边界。** 无论平台怎么描述（Session 也好、Cookie 也好），本质上都是把你账号的登录凭证交给第三方，由它代为访问官方页面完成付款。凭证不是密码，但你得清楚一点：凭证本身就是能访问账号的东西。这不是 BeWild 一家的问题，任何"帮你代付"的服务都绕不开这个机制。介意的话，就走 App 内购那条路。

**账号本身的状态很关键。** 代订阅只是在官方页面上完成一次正常的订阅付款，它不能替你解决账号本身的隐患。如果你的 Claude 账号当初是用极不稳定的 IP、可疑的接码号码注册的，账号本身就在风控名单上，那用什么方式付款都救不回来。

**续费不是百分之百稳定。** 有用户公开记录过在 BeWild 上遇到续费异常的情况——订单显示完成但订阅没生效，或者到了续订节点没有自动续上，后续通过联系客服获得了退款或补偿方案。买多个月套餐等于把后续月份的续订交给平台，这一点要有心理准备。

**退款规则要以当期条款为准。** 社区里对退款的讨论并不统一，既有顺利拿到退款的案例，也有关于退款手续费以及"账号被封需先向官方申诉、申诉失败如何处理"的争议。下单前把平台当前的退款政策读一遍，比事后争论有用。
